# OClock — Liquid Glass لأندرويد

تحويل ملف HTML المرفق إلى تطبيق أندرويد محلي بواجهة زجاجية. يدعم Android 8.0 (API 26) فما أحدث، مع Android System WebView محدث.

## تنزيل APK من GitHub

1. افتح تبويب **Actions** ثم **Build Android APK**.
2. اختر آخر تشغيل ناجح للفرع المطلوب، أو شغّله يدويًا باستخدام **Run workflow**.
3. من **Artifacts** نزّل **OClock-Android-APK** وفك ضغطه.
4. ثبّت `app-debug.apk` على الهاتف، واسمح بالتثبيت من هذا المصدر عند طلب أندرويد.

الملف Debug APK موقّع تلقائيًا للتجربة، وليس إصدار متجر. قد يتغير مفتاح الاختبار بين تشغيلات GitHub؛ إذا رفض الهاتف التحديث، احذف النسخة السابقة أولًا (هذا يمسح إعداداتها). للنشر يلزم مفتاح Release خاص وثابت لا يوضع في Git.

## التحسينات

- تحميل HTML والخطوط والخلفيات المولّدة من داخل APK، دون اتصال (الطقس يحتاج إنترنت).
- حركات ارتداد عند الضغط لا تستبدل تحولات السحب الموجودة.
- وضع خفيف تلقائي عند توفر مؤشرات ذاكرة/معالج منخفضة؛ بعض WebView لا يكشف هذه المؤشرات.
- احترام إعداد تقليل الحركة، خفض دقة رسم الساعة في الوضع الخفيف، وتجنب تحديثها عندما تكون الواجهة مخفية.
- اختيار الصور من منتقي النظام دون إذن للوصول الشامل للملفات.
- الكاميرا بعد الإذن فقط، وإيقافها عند مغادرة الواجهة.
- زر الرجوع يغلق المحرر أو الكاميرا أو المصباح قبل الخروج.
- حفظ التخصيص محليًا على الجهاز؛ لا خادم ولا حساب.

## الاستخدام والحدود

انقر مرتين على الخلفية لفتح التخصيص. اضغط مطولًا على الساعة لتعديل حجمها.

هذا **تطبيق محاكاة لشاشة القفل** وليس شاشة قفل نظامية، ولا يغيّر أمان الهاتف. مشغل الموسيقى والمصباح المرئي واجهة تجريبية من الملف الأصلي وليسا تحكمًا بموسيقى النظام أو LED. الطقس مضبوط على بغداد. المؤثرات تعتمد على WebView وGPU؛ لا يمكن ضمان معدل إطارات ثابت على كل الهواتف. لم يُختبر على أجهزة فعلية بعد.

## التطوير

```sh
npm ci
npm test
npm run dev
# معاينة على المنفذ 5173
npx playwright install --with-deps chromium
node scripts/browser-check.mjs
```

لبناء أندرويد محليًا: ثبّت JDK 17 وAndroid SDK 35 وGradle 8.9، ثم:

```sh
cd android
gradle :app:assembleDebug :app:lintDebug
```

المخرجات: `android/app/build/outputs/apk/debug/app-debug.apk`.

الخطوط المضمّنة عبر Fontsource؛ تراخيصها في `web/fonts/`.
